# 🐈 AbyssinianCAT (AbyssCAT)

> **Current Status: 🚧 In Development**
> *This plugin is currently under active development. Features may be unstable.*

**AbyssCAT** is a lightweight **Computer-Assisted Translation (CAT)** plugin built for [Obsidian](https://obsidian.md).

It transforms your Obsidian workspace into a professional translation environment, allowing you to translate Markdown documents sentence-by-sentence while preserving the original formatting.

## ✨ Main Features (Planned)

* **Smart Splitting**: Splits your markdown files into individual sentences automatically.
* **Two-Column View**: Provides A classic CAT two-column layout.
* **Keep the Format**: Exports the translation text into a new file while preserving the original formatting.

## 👍 Recommendation

I understand that translation projects can be complex consisting of multiple files. Unfortunately, translation project management is currently out of scope for AbyssCAT.

For project management, I recommend using the [Longform](https://github.com/kevboh/longform) plugin alongside AbyssCAT.
